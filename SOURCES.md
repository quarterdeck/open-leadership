# Sources

This file lists each source consulted for Open Leadership, the facts taken from it, and its
licence. All sources were consulted on 18 November 2026 unless a row says otherwise.

Rules:

- From a copyright source we take facts only (levels, sizes, hours, credits, titles, assessment
  methods). We take no text, items, scoring or diagrams.
- From an openly licensed source we may summarise, with attribution.
- "Opened" says if the page itself was read. "No" means that the fact came from a search summary
  and a person must confirm it before OL relies on it.

The notes that use these sources are in [research/source-notes.md](research/source-notes.md) and
[research/name-clash-report.md](research/name-clash-report.md).

the subject, and the citations were written from memory. A person must check a citation before

takes the idea only: no text, no diagram and no name of a model.

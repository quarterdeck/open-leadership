# Qualifications

Version 0.2.0 (draft). Each qualification is a set of units from the [unit
bank](../framework/unit-bank/README.md). Each has five documents: a specification, unit summaries,
an assessment guide, a centre guide and a learner handbook. Open Leadership is an independent,
unregulated framework.

## Core units

### [OL3-COA-01](../../../framework/unit-bank/OL3-COA-01.md): Coaching skills for managers

Core unit. 5 credits. 50 hours.

This unit enables the learner to use listening, questions and feedback to coach a person at work.

Learning outcomes:

1. Explain what coaching is and when a manager can use it
2. Use listening, questions and feedback in a coaching conversation
3. Review their own use of coaching skills

### [OL3-COA-02](../../../framework/unit-bank/OL3-COA-02.md): Coaching in practice

Core unit. 5 credits. 50 hours.

This unit enables the learner to complete and review a set of coaching conversations at work.

Learning outcomes:

1. Plan a set of coaching conversations with a person at work
2. Carry out a set of coaching conversations
3. Review the coaching and their own practice
